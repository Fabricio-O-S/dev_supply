# Portfólio de Data Analytics & Suprimentos — Fabrício Silva

Plataforma profissional e cockpit de inteligência analítica desenvolvida para apresentar soluções em **Data Analytics**, **Supply Chain** e **Automação de Dados com Python & SQL**.

---

## 📌 Visão Geral

Este portfólio reúne estudos de caso reais e simulados de grande impacto corporativo, unindo a visão estratégica da gestão de compras ao poder de processamento da programação e inteligência de dados.

### Destaques e Métricas Efetivas
- **+R$ 1.2M em Savings**: Redução de custos comprovada em negociações diretas/indiretas e análises de *Strategic Sourcing*.
- **40+ Unidades Atendidas**: Cobertura logística e contratos corporativos em âmbito nacional.
- **100% Automação em Saneamento**: Processamento massivo de bases de dados PDM, auditoria de alíquotas NCM e leitura de XMLs de NF-e via Python.

---

## 🛠️ Stack Tecnológica

- **Frontend & UI/UX**: HTML5 Semântico, Tailwind CSS, Google Fonts (Inter), Google Material Symbols, FontAwesome, SweetAlert2.
- **Data Analytics & Visualização**: Power BI (DAX, Modelagem Star Schema), Excel Avançado.
- **Engenharia de Dados & Automação**: Python (Pandas, Openpyxl, Requests, Flask), SQL (PostgreSQL, SQLite, MySQL).
- **Gestão de Processos & ERP**: TOTVS, SAP, Strategic Sourcing, Gestão de Estoques e Inventários.

## 📁 Arquitetura do Projeto

```text
portfolio-data-analytics/
├── assets/
│   ├── css/          # Estilos customizados e utilitários
│   └── js/           # Tema escuro/claro, filtros e modais interativos
├── images/           # Capturas dos dashboards e fotos de exibição
├── src/              # Scripts Python de processamento e dados
├── data/             # Bases e relatórios de entrada/saída (.csv, .xlsx, .json)
├── config/           # Configurações de ambiente
├── logs/             # Registros de execução e tratamentos de erros
├── tests/            # Testes automatizados e validações
├── docs/             # Regras de PDM, NCM e documentação funcional
├── index.html        # Página principal com métricas e filtros de projetos
├── curriculo.html    # Trajetória profissional e matriz de competências
└── projeto_*.html    # Páginas detalhadas de estudo de caso de cada projeto
```

## 💡 O que aprendi neste projeto

- **Design System com Tailwind CSS & Tema Dinâmico**: Implementação de arquitetura CSS limpa e responsiva com alternância de tema escuro/claro nativo via `localStorage`.
- **Refatoração semântica sem IA boilerplate**: Remoção total de comentários didáticos genéricos para entregar um código limpo, profissional e com foco em performance corporativa.
- **Engenharia de Recursos para Suprimentos**: Criação de visualizadores dinâmicos e modais de alto impacto para demonstrar resultados em *Strategic Sourcing*, *OTIF*, *Saving* e *DIFAL/ICMS-ST*.
