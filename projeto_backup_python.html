Rotina Automatizada de Backup & Registro de Logs

Script para automatização de rotinas de cópias de segurança de bancos de dados locais e arquivos de dados estratégicos, garantindo retenção contínua e rastreabilidade total de execuções.

Frequência

Diária / Cron

Execução agendada sem intervenção humana

Compressão

Zip / Gzip

Redução expressiva do espaço consumido

Registro de Erros

Módulo Logging

Rastreabilidade na pasta /logs

dns Contexto & Blindagem da Rotina

Rotinas de backup silenciosas são o pior tipo de falha: só aparecem quando já é tarde para recuperar o dado. O script trata cada etapa dentro de um bloco defensivo, registra toda execução (sucesso ou falha) em log estruturado com timestamp, e devolve um status explícito para o processo agendado (cron) que o dispara diariamente.

terminal Rotina de Backup com Tratamento Defensivo

def executar_backup_diretorio(origem_dir: str, destino_zip: str) -> bool:
    """Compacta a pasta de origem gerando um arquivo .zip de segurança"""
    logger = configurar_logger()
    try:
        if not os.path.exists(origem_dir):
            logger.error(f"Diretório de origem não encontrado: {origem_dir}")
            return False
        with zipfile.ZipFile(destino_zip, 'w', zipfile.ZIP_DEFLATED) as zipf:
            for root, dirs, files in os.walk(origem_dir):
                for file in files:
                    zipf.write(os.path.join(root, file), os.path.relpath(...))
        logger.info(f"Backup concluído com sucesso: {destino_zip}")
        return True
    except Exception as e:
        logger.error(f"Falha durante a execução do backup: {str(e)}")
        return False
