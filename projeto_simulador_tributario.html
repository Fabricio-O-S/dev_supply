Simulador Tributário de Compras Interestaduais (ICMS-ST & DIFAL)

Ferramenta desenvolvida em Python para simular a carga tributária real no momento da cotação com fornecedores de outros estados, prevenindo custos surpresa de imposto na entrada da mercadoria.

calculate Problema Fiscal Resolvido

Muitas vezes, uma proposta comercial de um fornecedor de outro estado parece mais barata no preço nominal, mas torna-se mais dispendiosa ao incidir o Substituição Tributária (ICMS-ST) ou o Diferencial de Alíquota (DIFAL). O sistema calcula instantaneamente o desembolso total efetivo da operação.

terminal Snippet de Código Python (Regra de Negócio)

def calcular_difal(valor_operacao, aliq_interestadual, aliq_interna_destino):
    """Calcula o Diferencial de Alíquota (DIFAL) da operação"""
    base_calculo = valor_operacao
    imposto_origem = base_calculo * (aliq_interestadual / 100)
    imposto_destino = base_calculo * (aliq_interna_destino / 100)
    valor_difal = imposto_destino - imposto_origem
    return max(0.0, round(valor_difal, 2))
