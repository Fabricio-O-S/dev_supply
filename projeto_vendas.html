analytics Desafio & Solução Desenvolvida

Em cenários comerciais de alto volume de transações, a tomada de decisão dependente de planilhas isoladas acarreta perda de agilidade. O projeto estruturou uma arquitetura analítica conectada diretamente ao banco de dados relacional, permitindo aos diretores de vendas identificar gargalos em tempo real por categoria de produto e filial.

A solução envolveu a criação de um modelo de dados otimizado em formato Star Schema (Esquema Estrela), isolando transações brutas na tabela fato e enriquecendo com dimensões temporais, territoriais e de cadastro de produtos.

code Destaques Técnicos DAX & SQL

Métricas calculadas nativas no Power BI via DAX com suporte a inteligência temporal (Time Intelligence), habilitando comparações YoY (Year-over-Year) e MoM (Month-over-Month):

// Faturamento YTD (Year-to-Date)
Faturamento_YTD = TOTALYTD(SUM(fVendas[ValorTotal]), dCalendario[Data])

// Margem Bruta %
Margem_Bruta_% = DIVIDE([Lucro_Bruto_Total], [Faturamento_Total], 0)
